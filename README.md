# 居家空間規劃

單一網頁檔的室內設計工具：2D 平面配置、3D 鳥瞰／室內漫遊、天花板、46 種家具（9 類）、風格配色、即時估價。

## 怎麼用
- 電腦：直接雙擊 `index.html`，用 Edge 或 Chrome 開啟（3D 需要連網載入 three.js）。
- 設計會自動存在該瀏覽器；換裝置請用「匯出／匯入」。

## 放上 GitHub Pages（手機也能開）
1. GitHub 新增 Public repo，名稱 `room-planner`。
2. 上傳本資料夾的 `index.html`（檔名不要改）。
3. Settings → Pages → Deploy from a branch → `main` / `(root)` → Save。
4. 1～2 分鐘後開啟：https://bigjasonbigbig.github.io/room-planner/

更新版本時，只要再上傳新的 `index.html` 覆蓋即可。
